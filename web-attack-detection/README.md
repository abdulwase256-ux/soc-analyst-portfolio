# Web Attack Detection and Investigation

## 1. Project Overview
This project documents my web attack detection learning through LetsDefend labs and simulated cybersecurity investigations.

## 2. Objective
To understand common web application attacks and learn how security analysts investigate suspicious activity.

## 3. Attack Types Covered
- Cross-Site Scripting (XSS)
- SQL Injection (SQLi)
- Command Injection
- Insecure Direct Object Reference (IDOR)
- Remote File Inclusion (RFI)
- Local File Inclusion (LFI)

## 4. Investigation Process
1. Reviewed the available lab scenario and evidence.
2. Identified the attack type being investigated.
3. Examined the relevant indicators available in the exercise.
4. Considered the potential impact and alternative explanations.
5. Documented the evidence and conclusions.

## 5. Evidence and Findings
For each attack type, document:
- **Attack type:** [Name]
- **Evidence reviewed:** [What you actually examined]
- **Observed indicators:** [Your observations]
- **Potential impact:** [Explain the risk]
- **Conclusion:** [What the evidence supports]

## 6. Defensive Considerations
Depending on the attack, defenses may include input validation, parameterized queries, appropriate access controls, safe file handling, and security monitoring.

## 7. Key Learning Outcomes
- Learned about common web application attack techniques.
- Practiced examining security investigation evidence.
- Developed an understanding of web attack risks and defensive controls.
