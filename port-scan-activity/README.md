# Port Scan Activity Detection and Investigation

## 1. Project Overview
This project documents my learning about port scanning and its investigation in a simulated SOC environment.

## 2. Objective
To understand how port scanning may appear in network security events and how analysts assess whether the activity is suspicious.

## 3. Investigation Process
1. Reviewed the available scenario and network evidence.
2. Identified the source and destination information where available.
3. Examined relevant ports, timestamps, and connection outcomes.
4. Considered whether the activity could indicate scanning or legitimate administration.
5. Documented observations and recommended follow-up checks.

## 5. SOC Analyst Considerations
A high number of connection attempts across different ports may indicate scanning, but the pattern, source, target, and surrounding context should be checked before reaching a conclusion.

## 6. Recommended Follow-Up
Depending on the evidence, review related firewall and IDS/IPS events, determine whether the source is authorized, and escalate according to the organization's incident-handling procedures when warranted.

## 7. Key Learning Outcomes
- Learned the purpose and indicators of port scanning.
- Practiced interpreting network activity.
- Learned to avoid classifying activity as malicious without sufficient evidence.
